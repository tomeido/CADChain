# CADChain ⛓️

> 브라우저에서 CAD를 그리고, 블록체인에 저장·검증하는 MVP

## 기능

- **CAD 드로잉** — 직선, 사각형, 원, 자유곡선, 텍스트
- **블록체인 저장** — SHA-256 해싱 + Proof-of-Work 마이닝
- **블록 탐색기** — 블록 목록, 프리뷰 썸네일, 해시 조회
- **도면 불러오기** — 블록에서 저장된 도면 복원
- **체인 검증** — 전체 블록체인 무결성 검증
- **캔버스** — 그리드, 스냅, 줌/팬, Undo/Redo

## 기술 스택

- Vanilla HTML / CSS / JavaScript
- Web Crypto API (SHA-256)
- LocalStorage (데이터 영속성)
- 서버 불필요 — 100% 클라이언트 사이드

## 실행

```bash
npx serve . -l 3000
```

→ http://localhost:3000

## 사용법

1. 왼쪽 툴바에서 도구를 선택합니다 (직선, 사각형, 원 등)
2. 캔버스에서 드래그하여 도형을 그립니다
3. 우측 상단 **블록체인에 저장** 버튼을 클릭합니다
4. 우측 패널에서 블록 탐색기를 확인합니다
5. **검증** 탭에서 체인 무결성을 검사할 수 있습니다

## 단축키

| 키 | 기능 |
|---|---|
| `Alt + 드래그` | 캔버스 이동 |
| `마우스 휠` | 줌 인/아웃 |
| `Ctrl + Z` | 되돌리기 |
| `Ctrl + Y` | 다시 실행 |
| `Delete` | 선택된 도형 삭제 |
| `더블클릭` | 텍스트 입력 (텍스트 도구) |
